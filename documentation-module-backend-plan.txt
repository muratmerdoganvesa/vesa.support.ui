Dokumantasyon Modulu Backend Plan

Bu frontend MVP'yi gercek veriye baglamak icin backend tarafinda en az su yapi yeterli olur.
En temiz yaklasim: departments, libraries, documents/pages, templates, favorites, authors ekseninde ilerlemek.

Onerilen Endpointler

1. GET /api/documentation/dashboard
Amac: dashboard icin tek cagrida ozet kartlari, son guncellenenler, favoriler, one cikanlar ve departman kartlarini dondurmek.

2. GET /api/documentation/sidebar
Amac: sol sidebar icin sections, libraries, favorites, templates ozetini vermek.

3. GET /api/documentation/departments
Amac: tum departmanlari listelemek.

4. GET /api/documentation/departments/{departmentId}/libraries
Amac: secili departmanin altindaki library listesini vermek.

5. GET /api/documentation/libraries
Amac: filtreli library listesi.
Query onerisi: ?departmentId=&search=&favoriteOnly=&page=1&pageSize=20

6. GET /api/documentation/libraries/{libraryId}
Amac: library header bilgisi ve owner bilgisi.

7. GET /api/documentation/libraries/{libraryId}/pages
Amac: library icindeki sayfalari listelemek.
Query onerisi: ?search=&status=&page=1&pageSize=20

8. GET /api/documentation/pages/{pageId}
Amac: page detail viewer ekrani.
Bu endpoint zengin icerik bloklarini donmeli.

9. GET /api/documentation/pages/{pageId}/history
Amac: son duzenlemeler veya versiyon gecmisi.
Ilk fazda opsiyonel.

10. GET /api/documentation/templates
Amac: template listesi.

11. GET /api/documentation/templates/{templateId}
Amac: template detay ekrani veya preview.

12. GET /api/documentation/authors/{authorId}
Amac: yazar karti detayini bagimsiz cekmek istersen.

13. POST /api/documentation/favorites/libraries/{libraryId}
Amac: library favoriye ekleme.

14. DELETE /api/documentation/favorites/libraries/{libraryId}
Amac: library favoriden cikarma.

15. GET /api/documentation/search
Amac: global arama.
Query onerisi: ?q=onboarding&type=all|library|page|template

16. POST /api/documentation/pages
Amac: ileride create.

17. PUT /api/documentation/pages/{pageId}
Amac: ileride update.

18. DELETE /api/documentation/pages/{pageId}
Amac: ileride delete veya soft delete.

Zengin Icerik Icin Blok DTO Onerisi

Viewer ekrani icin en esnek model bu olur:

PageContentBlockDto

- type: string
- orderNo: int
- payload: json

type ornekleri:
- heading
- paragraph
- bullet_list
- checklist
- code_block
- link_list
- table
- accordion

payload ornek mantigi:
- heading: { "level": 2, "text": "Neden Bu Modulu Ekliyoruz?" }
- paragraph: { "text": "..." }
- code_block: { "language": "tsx", "content": "..." }
- table: { "headers": ["Alan","Durum"], "rows": [["Dashboard","Ready"]] }

- Bir library cok page icerir.
- Bir page cok block icerir.
